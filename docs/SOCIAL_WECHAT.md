# 微信公众号 · ASCII 艺术模拟器（ASCII Simulation Art Console）

**标题**
把素材变成字符画

**正文**
最近做了个浏览器工具——ASCII 艺术模拟器。把 3D 模型、视频、图片丢进去，当场转成字符画。起初只是想复刻一段视频里的 ASCII 卡片效果，后来发现真正难的不是"换字符"，而是"换完还清楚"。

核心决定：不碰 DOM，只跑 GPU。所有素材先渲染成一张 Three.js 纹理，再挂一个全屏 GLSL 后处理 shader，逐格采样，把亮度、深度、位置映射成字符和颜色。所以你拖滑块、换素材、让模型转，交互始终跟手、不卡。

最难的是 3D。网上下载的 GLB 模型，尺寸、轴心、材质千奇百怪，只靠亮度会把结构照平。我的解法是加一条法线分析通道：用表面朝向生成可控明暗，再并行渲染深度纹理实时归一化。ASCII shader 把深度、梯度、曲率、轮廓、法线明暗合在一起，决定每个字符的类型、大小、透明度。于是连 0 和 1，都能读出表面的高低。

它现在能处理 GLB/GLTF（含 Draco、Meshopt 压缩）、图片、透明 SVG、视频；字符集、密度、对比度、配色都能调；默认 9:16，左键转、滚轮缩放、中键挪；能导出 PNG、15 秒 WebM、可嵌入网页的 Web Component。

一个好用的创作工具，既需要很多参数，也需要可预期的默认值。参数给你自由，默认值让你敢动手。视觉的尽头，往往不是加得更多，而是把一种语言说到极致。
