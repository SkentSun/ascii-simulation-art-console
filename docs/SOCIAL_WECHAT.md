## 正文

### 一、起点：一篇素材帖，和一堆「这怎么做的」

故事的开始，是一篇介绍 ASCII 网站效果的素材文章。

那阵子我在看一些把 0 和 1 当视觉语言用的官网风格——安静、克制，又特别有辨识度。顺手发了篇素材文章，没想太多。结果反馈出乎意料地好，评论区几乎一面倒地在问同一件事：「这效果到底怎么做的？」

被这股热情推着，我干脆用了个周末，vibecoding 了一个浏览器里就能跑的工具。做完觉得，与其藏着，不如直接 MIT 开源，大家随便拿去用。

那个周末的小实验，最后长成了一个可以处理 3D 模型、图片、透明 SVG 和视频的实时视觉控制台——**ASCII 艺术模拟器**（ASCII Simulation Art Console）。

### 二、一个决定：不碰 DOM，只跑 GPU

很多字符画的实现，是把屏幕切成网格，每个格子放一个 `<span>` 或 `<div>` 文字节点。素材一大、参数一调，几千上万个 DOM 节点同时重排，页面立刻就卡了。

我选了另一条路：

所有素材，先统一渲染成一张 Three.js 纹理；再挂一个全屏的 GLSL 后处理 shader，逐格采样，把每个字符单元的亮度、深度、位置，映射成具体的字符和颜色。

这样一来，无论你是在拖滑块、换素材，还是让模型转起来，真正的计算都发生在 GPU 里。交互始终跟手，不卡。

### 三、最难的 3D：让 0 和 1 也能「立」起来

图片和视频的字符化，靠亮度就够了。但 3D 不一样。

网上下载的 GLB 模型，尺寸、轴心、材质、光照千奇百怪。如果只依赖原始材质的亮度，结构很容易被「照平」——明明是个有起伏的雕塑，字符画出来却像一块平板。

我的解法是加一条**专用的法线分析通道**：不信任模型自带的材质，而是用表面的朝向生成可控的灰度明暗。同时并行渲染一张深度纹理，把它的近 / 远范围，按当前模型实时重新归一化。

最后，ASCII shader 把这几路信号合在一起：

- 归一化后的相机深度
- 局部深度梯度
- 深度曲率
- 轮廓过渡
- 视图法线明暗

它们共同决定每个字符的「类型、尺寸、透明度、间距」。

效果很有意思：因为二进制字符 0 和 1 的视觉重量几乎一样，光换字符区分不出起伏；但这套分析会去改字符的「大小和透明度」。于是哪怕只用 0 和 1，也能读出模型表面的高低。

### 四、它现在能做什么

- **素材**：GLB/GLTF（含 Draco、Meshopt 压缩）、图片、透明 SVG、MP4/WebM 视频
- **字符**：自定义字符集、密度、对比度、噪点、字符尺寸
- **颜色**：三色渐变、经典混合模式、Light / Dark 主题
- **动效**：数字瀑布、扫描线、波浪、故障（glitch）
- **画布**：9:16、16:9、1:1 及自定义尺寸
- **文案**：可编辑的 H1 与简介文字层
- **导出**：PNG、15 秒 WebM、可嵌入网页的 Web Component

交互也直接：左键拖拽旋转 3D，中键拖拽移动素材或文案层，滚轮在画布上缩放素材、画布外缩放预览。所有变换对「媒体」和「文案」分开存储，挪动画布不会误伤素材本身。

### 四·五、四个被低估、却决定成品归不「属于你」的自由度

前面讲的是「能不能转」。但真正让一张图能直接发出去，是四个细节：

- **自定义文案**：H1 与简介文字层，字号、字体、对齐、文字颜色全可改，还能单独拖到画面任意位置，不和素材抢地方。
- **自定义图形位置**：左键旋转、中键移动、滚轮缩放，素材和文案的变换分开存储——你挪动画布，不会误伤素材本身的像素。
- **自定义任意配色**：背景、页面、文案色，加上一段三段式字符渐变；四套推荐色板不够，就上任意取色器，Light / Dark 一键切。
- **画布尺寸不挑平台**：默认 9:16 竖屏，但已预设各社媒通用比例（16:9、1:1 等），还能填任意像素自定义尺寸——发出去不用再裁。

这四件事凑齐，才算把一个「效果」变成一件「能发的作品」。

### 五、重新理解「清晰」

做完这一轮，我对 ASCII effect 的看法变了。

它根本不是简单的「亮度换字符」。真正决定画面清不清晰的，是采样尺度、字符的视觉重量、深度归一化、边缘信号和颜色系统之间的配合。

一句更实在的话：一个好用的创作工具，既需要很多参数，也需要可预期的默认值。参数给你自由，默认值让你敢动手。

### 六、接下来

还想继续啃几块硬骨头：更稳的实时分割、GPU 多尺度边缘检测，以及更适合动态品牌视觉的预设系统。既然已经开源，也欢迎大家一起提 PR、一起把这个周末的小实验，做得更扎实。

如果你也在做品牌视觉、官网，或者单纯想把「代码感」用对地方——这个工具，或许能给你一点不一样的思路。
