## 正文

做设计的都懂：官网最容易陷进"蓝紫渐变 + 晶圆芯片 + 商务握手"的素材套路。

前阵子我发了篇介绍 ASCII 网站效果的素材文章——就是那种把 0 和 1 当视觉语言用的官网风格。没想到反馈出乎意料地好，评论区全在问「这效果到底怎么做的」。

被这股热情推着，我干脆用了个周末，vibecoding 了一个浏览器里就能跑的工具——**ASCII 艺术模拟器**（ASCII Simulation Art Console）。做完直接 MIT 开源，大家随便拿去用。越用越觉得，它把"克制"做成了一种高级感 👇

———

✅ 喜欢它「不堆 DOM，只跑 shader」  
很多字符画做法是铺几千个文字节点，一拖参数就卡。它反过来：素材先渲染成一张纹理，再用 GPU 里的 GLSL shader 逐格采样、按明暗换字符。丝滑得不像在跑 3D。

✅ 喜欢它「连 0/1 都能立起来」  
3D 最难——网上下载的模型尺寸、轴心、材质全乱。它加了专门的法线分析通道，把实时深度、边缘、曲率一起喂给字符。结果连二进制 0 和 1，都能看出表面的起伏。这才是真功夫。

✅ 喜欢它「四种素材通吃」  
3D（GLB/GLTF，含 Draco、Meshopt 压缩）、图片、透明 SVG、视频（MP4/WebM）——丢进去就转。不用再为每种格式写一套逻辑。

✅ 喜欢它「为手机短视频而生的比例」  
默认就是 9:16 竖屏支持，左键拖转、滚轮缩放、中键移位置。做完直接导出 PNG、15 秒 WebM，或一个能嵌网页的 Web Component。

———

✨ 四个被低估、但让你直接出片的自由度
• **自定义文案**：H1 + 简介文字层，字号 / 字体 / 对齐 / 文字颜色全可改，还能单独拖到画面任意位置
• **自定义图形位置**：左键转、中键移、滚轮缩放，素材与文案变换分开存储——挪动画布不会误伤素材本身
• **自定义任意配色**：背景 + 页面 + 文案色 + 三段字符渐变，四套推荐色板不够，就上任意取色器，Light / Dark 一键切
• **画布尺寸不挑平台**：默认 9:16 竖屏，但已预设各社媒通用比例（16:9、1:1 等），还能填任意像素自定义尺寸——发出去不用再裁

———

🎯 它适合谁（设计师选型参考）：  
• AI / 数据 / 开发者工具：字符即视觉，语义天然契合  
• 想甩掉「素材感」、建立独特视觉资产的产品  
• 要做竖屏短视频、又嫌实拍 / 版权麻烦的团队

———

📌 好的视觉不是加得更多，而是敢把一种语言，说到极致。
