# 小红书 · ASCII 艺术模拟器（ASCII Simulation Art Console）

**标题（两行）**
把素材变成字符画
一个浏览器里就能玩的实时工具

**正文**
做设计的都懂，官网最容易陷进"蓝紫渐变 + 晶圆芯片"的素材套路。我做了个实验性工具 ASCII 艺术模拟器，专门把任何素材实时转成字符画，越用越觉得"克制"本身就是高级感。

✅ 不堆 DOM，只跑 GPU
很多字符画是铺几千个文字节点，一拖就卡。它反过来：素材先渲染成纹理，再用 GLSL shader 逐格采样换字符，丝滑得像没在跑 3D。

✅ 连 0/1 都能立起来
3D 最难——模型尺寸轴心材质各异。它加了法线分析通道，把深度、边缘、曲率喂给字符，连二进制 0 和 1 都看得出起伏。

✅ 四种素材通吃
3D（GLB/GLTF，含 Draco、Meshopt 压缩）、图片、透明 SVG、视频，丢进去就转。

✅ 为手机而生
默认 9:16 竖屏，左键转、滚轮缩放、中键移位置；导出 PNG、15 秒 WebM、或嵌网页的 Web Component。

好的视觉不是加得更多，而是敢把一种语言说到极致。你会想用它做自己的项目吗？
